# Lot43 Gallery

**[Download and use the standalone photo layout editor](share/README.md)** · **[Live starter demo](https://dustchambers.github.io/beltline-app-gallery/share/)**

The `share/` folder contains a self-contained HTML starter and setup instructions, based on the latest committed layout engine. Its MIT license applies only to that folder. Photographs elsewhere in this repository are excluded.

The remaining files are the original Lot43/Webflow gallery implementation.
